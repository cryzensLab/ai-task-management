ListingFlow Quick Reference Guide

1. Linking Your Local Image Folder

Click Link Local Folder in the top bar. Choose your local folder containing raw catalog shots and generated AI outputs. All files remain strictly on your local disk; only exact filenames and normalized vector annotations are stored in the shared database.

2. The Production QC Loop

  • Start: Creator moves card from Scheduled to In progress.
  • Outputs: Creator adds output filenames and moves card to Ready for QC (requires ≥ 1 output).
  • Review: Reviewer opens Side-by-side Compare, marks each output Approved or Needs Fix, draws normalized vector markup directly on issues, and adds revision notes.
  • Changes Requested & Resubmit: If any output needs fix, card moves to Changes requested. Creator updates files, clicks Resubmit (advances round, keeps full audit history), and sends back to Ready for QC.
  • Pass & Delivery: Once all outputs are Approved, card reaches Passed QC and can be marked Delivered with listing URL.

3. Infinite Whiteboard (Powered by tldraw.dev)

The whiteboard embeds the full-featured, collaborative tldraw infinite canvas. Enjoy limitless moodboarding, freehand drawing, vector geometry, sticky notes, frames, image embeds, laser pointer, and real-time multiplayer whiteboard rooms.

4. Monthly Archive & Reset Routine

Admins can select any month key (e.g. 2026-10), export a self-contained JSON snapshot, and safely clear the month with a confirmed progress routine. Tasks can be restored anytime as read-only or duplicated into fresh pipeline tasks.
